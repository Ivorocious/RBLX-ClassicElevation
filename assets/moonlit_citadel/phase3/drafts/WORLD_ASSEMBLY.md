`WorldPlan.Get(Layout)` returns the placement array and a count summary. Every whole edit unit records `asset`, `library`, `localCF`, `scale`, `district`, `name` and optional `supportPath`. It is pure: it creates no instances and changes no layout records. The lead can export these fields and transform the actual manifest geometry/proxies for the final clearance check.

`WorldAssembly.Apply(course, Layout)` assembles those placements under `course.Decoration.Phase3World`. The lead should integrate both modules beside the final `MoonlitCitadelCourse.Layout`. It calls the existing accepted `MoonlitCitadel.MeshKit.Place` for BL02 units and clones verified templates directly from `MoonlitCitadel_P3World_C01Library` for P3 units. It never redirects or edits the accepted library/helper. All art remains anchored, noncolliding, and query/touch disabled. The module adds no lights or gameplay surfaces.
