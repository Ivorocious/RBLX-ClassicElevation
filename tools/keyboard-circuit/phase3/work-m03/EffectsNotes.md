# M03 archive effects implementation

`ArchiveEffectParts.Build(course, origin, template)` runs after Environment/Wayfinding/ArchiveBackdrop. `MapEnvironment.ArchiveEffectParts` contains inert invisible anchors, at most 64 thin underlight strips, 16 existing trace references distributed across all four families, 28 wave-bar anchors, four USB contact anchors and one low interior layer at local y=-129. Every part has collision/touch/query/shadows off. No dynamic lights, particles or SurfaceGuis are added. Each family must have nonzero underlight and trace counts; build assertions and per-family attributes enforce this.

`ArchiveEffects.Start(candidate, feedback)` is invoked by the actual F6 preview only when the candidate has `KCArchiveAmbience=true`. The existing general ambience controller must first restore its prior profile and set its local-script `KCArchiveYielded` attribute to that candidate's name. Until that acknowledgement, ArchiveEffects does not change Lighting. This prevents a second controller from writing an active profile or becoming the captured fallback.

Before the first Lighting write, effects take a unique client-only `KCArchiveLightingOwner` token. The general controller yields whenever this token is present, even after selection changes. Effects clear only their own token after every saved property and owned object has been restored/removed. This makes entry and exit independent of callback connection order; diagnostics report the live token and ownership.

After initial readiness resolves, the existing visibility branch rechecks Feedback readiness at most 5 times per second. Stopped/cancelled feedback or a failed readiness accessor ends the cosmetic profile and restores its captured state. This covers diagnostic cancellation after the preview's startup poll has completed. Untriggered wave timestamps are omitted from diagnostics so the receipt contains no infinite timestamp values.

One bounded Heartbeat update runs at most 30 times/second (20 for explicitly selected quality 1–3). It caches all owned parts; no world/key scans occur in the cosmetic loop. Underlight visibility checks occur at most 5 times/second. Four pooled trace heads travel intermittently along the existing decorative traces, with two at quality 1–3. Wave bars receive the existing Feedback key-entry signal before audio coalescing, so actual foot contact drives them without another detection path. Entries farther than 135 studs from that district's landmark are ignored; local viewing distance is 210 studs, 155 at quality 1–3. Nearby player entries use half-strength. Creamy is smooth, Thocky rises more heavily, Clacky alternates, Clicky flicks quickly. Key depression, audio asset/tuning and gameplay state are untouched.

USB contacts receive the existing readiness result: loaded-clip progress while loading, mint when ready, amber on degraded readiness and dark on cancellation/stopping. `KCPhase2CompletedLaps` increases cause a short four-contact sweep; current completed laps are captured on activation so selection/respawn does not replay older sweeps. Completed race state stays in diagnostics and progress remains authoritative on the server. No new countdown or gameplay clock is introduced.

Lighting, existing post-effect enable states, existing Atmosphere density/haze/glare and changed Sky properties are captured only after the acknowledgement. Fog stays far beyond the course; the faint depth layer lies 11 studs above the distant floor and 129 studs below origin. Gentle bloom has intensity 0.08, size 14, threshold 1.25. Explicit low quality disables bloom and depth entirely. Stop disconnects the one update and one key-entry subscription, removes its client-only visual/probe folders and owned lighting objects, and restores every captured setting. The preview registers cleanup before audio/effect startup; exit/restart, death/respawn, run-id changes, candidate removal and script shutdown stop the effects. Setup/update exceptions also stop and restore. Other map scripts and stored data are untouched.

Maximum wave envelopes are supplied as `MaxEffectFrame`/`MaxEffectSize` on each anchor. Bars grow upward with a fixed lower edge. Conservative max height is0.8+(1.2+1/60)*4.2=5.91studs for Thocky and0.8+(1+1/60)*3.1≈3.952studs for the other families, including quantization allowance. Every trace reference supplies an envelope centered at source.CFrame*CFrame.new(0,0.025,0), sized(source.Size.X,0.13,0.7). These envelopes include every local animated pose; root clearance fixtures should test them as virtual artwork boxes despite hidden anchors.
