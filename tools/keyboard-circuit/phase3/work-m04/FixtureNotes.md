# M04 verification tools

These 27 root Luau tools are adapted copies of the M03 tools. The M03 files, frozen evidence, geometry sources, global controllers and render scripts are unchanged by this helper. Native tools were not executed by this helper.

The exact candidate is `KeyboardCircuit_P3_M04_01`, revision `KC_P3_M04_01`, at the owner origin `(2222, 330, -1158)`. Native recovery and full source agreement use `ServerStorage.KeyboardCircuitPhase2Archive.Phase3FinalTuning20261009.M04Sources01`. The owned native proof folder is `KCP3M04NativeRecovery01` under that same holder; it must not already exist when beginning a fresh proof.

Required candidate inventory: 8,808 parts; 2,989 press targets; 282 colliders; 3,289 query parts; zero touch parts; 1,894 artwork parts; 28 snapshot sources including `ArchiveSkyConfig` and `WarningPlacements`. All 16 older courses must remain archived and their scripts disabled, including M02 and M03. The four global source rows include `ClassicAscentAmbience` and the unchanged `StudioDevController`; the caller compares all 32 returned byte/hash rows to the repository files.

`NativeRecovery.server.luau` retains full-source equality and native deserialize/fresh rebuild comparisons, including warning poses, artwork, GUI text/layout/fonts/draw distances, attributes, meshes, physics flags and internal references. `PreservationAudit.luau` retains the owner-live-M02 baseline, permanent contacts, key geometry, core gameplay source comparison and full body envelopes against visible art and virtual cosmetic bounds. `MotionClearance.luau` retains all eight authored swept mechanism volumes. `VisibilityAudit.luau` and `WarningCheck.server.luau` retain all 17 warning boards and their visibility/state receipts.

`CostAudit.server.luau` compares archived M02 to current M04 in Edit. It measures art shadows, gameplay flags, finite/unlimited SurfaceGui distances and legend classes, lights, particle emitters, beams and trails. The ordinary/special/display/warning key budgets are respectively 120/180/64/170 studs. Hazard displays, wayfinding and other existing displays are recorded separately. One authored `ArchiveEffects` Heartbeat callback is reported explicitly; actual update rate, active connection count and cleanup require client lifecycle diagnostics. Inventory counts do not prove FPS, memory, draw calls, startup latency or device performance.

The obsolete Phase2-I09 `IntegrationAudit.luau`, minimal three-global `SourceAgreement.luau`, and frozen-M02 `PresentationBudgetCheck.luau` are intentionally not copied. Owner-live-M02 `PreservationAudit.luau`, the 32-row `SourceAgreementFull.luau` and the current native `CostAudit.server.luau` cover their relevant requirements without retaining obsolete baselines or claims.

`EffectShapes.luau` retains frozen M02 geometry as a host, while loading the three current effect/config sources. This checks bounded cosmetic wave and contact samples; it does not replace native M04 lifecycle or sky-asset loading checks. `OfflineGeometry.luau` writes only M04-specific artifacts and validates the exact construction inventory. Compile all M04 root and source Luau files after effects are stable with `.tools/lune-0.10.5/lune.exe run tools/keyboard-circuit/phase3/work-m04/CompileFixtures.luau`.

The current 57 root/source files passed compilation before the final lifecycle guard. The focused lifecycle compiler then passed for the changed `EffectLifecycle.client.luau`.
