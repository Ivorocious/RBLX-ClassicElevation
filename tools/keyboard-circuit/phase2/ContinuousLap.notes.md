# Continuous normal-lap fixture

Install the existing `TraversalProbe.client.luau` in the selected Studio client first, then execute `ContinuousLap.client.luau`. Prepare a fresh, living, released participant with authoritative `KCPhase2NextGate = CP1`, lap1 and completedLaps0 before executing it. The fixture does not call Begin/Restart or change progression. Session's normal initial Begin places the participant on a recovery pad; that setup must happen before this test.

The fixture calls `Probe.Place` once on the main F00 checkpoint bay. Its returned setup includes the probe's settling-attempt count. The continuous interval starts after this settles. It then uses the installed probe's normal Humanoid movement/jumps for all 21 Layout.Main joins, all sixteen sequences, and CP1→CP2→CP3→F01→F00. It uses actual connector/entry/exit contacts, static traversal markers with Model-only bank lookup, the existing Enter hairpin turn, all eight mechanism paths, physical lift/shuttle carrying, and the sweep corridor jump. It does not position the character between sections.

Results are in `shared.KCP2ContinuousLap`. They include movement settings, setup, per-join/per-sequence results, probe movement records, waits and ride samples, authoritative attribute changes, filtered server gate/recovery records, final state and elapsed/continuous/wait seconds. A pass requires five natural server gate records in the expected order, one completed lap, all 21 joins/all sixteen sequences, and no increase in authoritative recoveries. Known admission windows and explicit checkpoint forward crossings are used. Fresh-window waits add delay; the duration describes this automated route policy.

A watchdog stops the probe, zeroes its movement command, cancels its worker and disconnects its monitor on failure, recovery, character/session change, unexpected position discontinuity, cancellation or the 300-second deadline. It does not stop the server session or move the character to safety. Set `shared.KCP2ContinuousLap.cancelRequested = true` to cancel. Run it alone on that client's movement probe; completion stops the probe binding, so reinstall TraversalProbe before later movement fixtures.

This source can test one continuous automated normal lap with real avatar support, carrying, waits and natural server progress when executed natively. A source/syntax check does not establish that result. It does not establish human racing pace, the 4–5-minute three-lap target, crowd capacity, device behavior, camera quality or performance. No native execution was performed by this helper.
